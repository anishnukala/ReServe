# Product Requirements

## MVP functional requirements

- FR-01 Create a donation
- FR-02 Validate required donor input
- FR-03 Discover candidate organizations
- FR-04 Filter incompatible recipients
- FR-05 Rank compatible recipients
- FR-06 Explain recommendations
- FR-07 Select and accept a match
- FR-08 Track accepted → picked up → delivered
- FR-09 Calculate prototype impact metrics
- FR-10 Keep food-safety decisions outside the AI/matching system

## Non-functional requirements

- Fast enough for an interactive donation workflow
- Mobile-responsive
- Explainable scoring
- Reports clear configuration errors when required services are unavailable
- External secrets remain server-side
- Displays only persisted or live provider data
