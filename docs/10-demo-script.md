# Demo Script

## Scenario

A donor has **35 lbs of refrigerated vegetarian pasta** that needs to be picked up within a few hours.

## Demo

1. Open `/donate`.
2. Show the optional natural-language description extraction.
3. Verify safety-critical fields manually.
4. Submit the donation.
5. Show the top three compatible organizations.
6. Open the score breakdown for the best match.
7. Select the recipient.
8. Mark the rescue picked up.
9. Mark the rescue delivered.
10. Open `/dashboard` and show impact.

## Main message

ReServe does not just find the nearest organization. It filters for operational feasibility and explains why a recipient is a strong match.
